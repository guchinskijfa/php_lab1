# Портал регистрации пользователей

Современная система регистрации и авторизации пользователей, разработанная с соблюдением коммерческих стандартов качества.

## Требования

- Docker & Docker Compose
- PHP 8.2+
- PostgreSQL 15+
- Apache с mod_rewrite и mod_headers

## Структура проекта

```
/workspace
├── app/
│   ├── public/                 # Точка входа приложения
│   │   └── index.php          # Front controller
│   ├── src/
│   │   ├── Config/            # Конфигурация
│   │   ├── Controllers/       # Контроллеры
│   │   ├── Models/            # Модели данных
│   │   ├── Services/          # Бизнес-логика
│   │   ├── Views/             # Представления
│   │   └── autoload.php       # PSR-4 автозагрузчик
│   ├── storage/logs/          # Логи приложения
│   └── .htaccess              # Настройки Apache
├── docker-compose.yml         # Конфигурация Docker
├── Dockerfile                 # Образ PHP/Apache
├── .env.example              # Пример переменных окружения
└── README.md                 # Документация
```

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
```

Отредактируйте `.env` файл и укажите ваши ключи reCAPTCHA:
- Получите ключи на https://www.google.com/recaptcha/admin
- Вставьте `SITE_KEY` и `SECRET_KEY` в соответствующие поля

### 3. Запуск через Docker Compose

```bash
docker-compose up -d --build
```

### 4. Доступ к приложению

- Веб-интерфейс: http://localhost:8080
- База данных: localhost:5432 (PostgreSQL)

## Функциональность

### Регистрация пользователя

Форма регистрации включает следующие поля с валидацией:

| Поле | Требования |
|------|-----------|
| Имя | 2-15 букв, только кириллица/латиница, без пробелов |
| Фамилия | 2-15 букв, только кириллица/латиница, без пробелов (одна фамилия) |
| Email | Валидный формат email |
| Логин | Минимум 6 символов, уникален |
| Пароль | Мин. 8 символов: строчные, прописные буквы, цифры, спецсимволы |
| Подтверждение пароля | Должно совпадать с паролем |
| Возрастная группа | "Мне есть 18 лет" / "Мне меньше 18 лет" |
| Пол | Мужской / Женский (radio buttons) |
| Принятие правил | Checkbox (обязательно) |
| reCAPTCHA | Защита от ботов |

### Авторизация

- Вход по логину и паролю
- Сессионная аутентификация
- Хеширование паролей алгоритмом bcrypt (cost=12)

### Личный кабинет

После авторизации пользователю доступно:

1. **Приветствие** с именем пользователя
2. **Статистика сайта**:
   - Общее количество зарегистрированных пользователей
   - Количество регистраций за текущий месяц
   - Фамилия последнего зарегистрированного пользователя
3. **Список всех фамилий** зарегистрированных пользователей
4. **Поиск пользователей** по имени или фамилии
5. **Переключение темы** (светлая/темная)
6. **Выход** из системы

### Переключение темы

- Кнопка переключения темы в шапке сайта
- Сохранение предпочтений в cookie (30 дней)
- Изменение цветового оформления всех элементов
- Динамическое изменение текста кнопки

## Технические особенности

### Архитектура

- **MVC-подобная архитектура** с разделением ответственности
- **PSR-4 автозагрузка** классов
- **Dependency Injection** через конструкторы
- **Repository Pattern** для работы с БД

### Безопасность

- **PDO с prepared statements** для защиты от SQL-инъекций
- **password_hash()/password_verify()** для безопасного хранения паролей
- **XSS защита** через htmlspecialchars()
- **CSRF защита** через SameSite cookie атрибут
- **Security headers** (X-Frame-Options, X-Content-Type-Options, etc.)
- **Валидация на клиенте и сервере**

### Валидация

- **Client-side**: HTML5 validation + JavaScript
- **Server-side**: Строгая валидация в ValidationService
- **AJAX проверка** уникальности логина/email

### Работа с данными

- **PostgreSQL** через PDO
- **Миграции** создаются автоматически при первом запуске
- **mysqli_fetch_array аналог** через PDO fetch()


Ответ:
```json
{"available": true, "taken": false}
```

## Разработка

### Добавление нового функционала

1. Создайте сервис в `src/Services/`
2. Добавьте контроллер в `src/Controllers/`
3. Создайте view в `src/Views/partials/`
4. Обновите роутинг в `public/index.php`

### Логирование

Логи сохраняются в `app/storage/logs/`
